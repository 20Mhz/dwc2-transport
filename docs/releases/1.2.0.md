# 1.2.0

Final experimental SDK release for Linux / ARMv6, distributed through the
[public repository](https://github.com/20Mhz/dwc2-transport) and
[v1.2.0 release](https://github.com/20Mhz/dwc2-transport/releases/tag/v1.2.0).
The C ABI is unchanged at major 1 / API 1.0.

## Changes

- Timestamped sampling windows and single-session timelines with conservative
  bounds for kernel observations, explicit unknown samples and address reuse.
- Session-scoped operator statements with independent attribution and receipt
  times; annotations never establish a physical action or its cause.
- Strict validation of completeness, provenance, parameters, errors, references
  and recomputed transition outcomes.
- Identity database 1.2.0 with primary references and explicit distinctions
  between application associations, recovery identities and unverified DFU.
- Deterministic ARMv6/source packaging, Git-free source provenance, runtime
  corresponding sources, license notices and relink objects.

## Delivered files and provenance

The ARMv6 archive contains executables, static SDK library, headers, Python
helpers, tests, source and relink objects. The separate source archive includes
build scripts and pinned runtime sources. Both include documentation, M7/M8
redacted evidence, source/build manifests and SHA-256 checksums.

The public Git repository starts with a reviewed distribution snapshot.
Historical development commits and raw USB captures remain local. The packaged
`REVISION`, `APPLICATION_REVISION` and manifests identify the original compiled
and application sources; the distribution tag identifies the repository snapshot.

## Validation and remaining limits

Native sanitizer, Linux contract, ARMv6/QEMU, Pi execution, installation,
Git-free source rebuild, deterministic packaging and privacy checks passed
locally. [M8 evidence](../evidence/m8-20261104/README.md) records exact hardware
results and source revisions. Hosted CI results are reported separately by
GitHub Actions and are not implied by these local checks.

M8 recorded 60 samples over 30 seconds at `05ac:1281`, successful descriptor
access and clean interrupted shutdown. **No identity transition was captured.**
The mode-entry experiment remains `PENDING_VERIFIED_PROCEDURE`. Earlier `12a7`
and `1281` sessions cannot establish the intervening transition. Model, firmware,
boot/security state and recovery/DFU protocol behavior remain unverified.

No recovery commands, mode switching, firmware operations or kernel capabilities
were added. Privacy scanning is pattern-based. Runtime provenance uses recorded
package versions and pinned corresponding sources; descriptor signatures were
not independently checked and the runtime was not rebuilt in this validation.
See the [operating guide](../guide.md) for commands and reproduction limits.
